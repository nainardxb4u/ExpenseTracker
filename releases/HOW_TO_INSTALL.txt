Weekly Grocery Android app
==========================

File:    GroceryMate.apk
Package: com.nainar.grocerymate
Name:    Weekly Grocery
Needs:   Android 5.0 or newer (phones and tablets, works offline)

How to install
--------------
1. Download GroceryMate.apk from this folder (or the GitHub release/source).
2. Copy it to your phone (Download, Drive, WhatsApp, USB, email).
3. Open the file on the phone.
4. If Android asks, allow installing apps from this source.
5. Tap Install, then Open.

How to use
----------
- This week: check off items you bought. Use + / − for quantity, pencil to edit, X to remove.
- Items: 28 predefined staples (milk, bread, rice, ...). Add, edit, or delete any item. Staples are copied into each new week. Tap Add to put an extra item on this week's list.
- History: saved weekly shops. Open a week to see bought vs missed. Copy missed items back to this week.

Your list, items, and weekly history stay on the phone.
